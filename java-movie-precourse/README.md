# java-movie-precourse

# 영화 예매 프로그램

## 1. 프로젝트 개요
목표: 쉽고 빠르게 영화를 예매할 수 있는 프로그램 구현
- 영화 상영 일정 관리
- 좌석 선택 및 가격 계산
- 포인트 및 할인 적용
- 여러 영화 예매 가능
- 테스트 중심 개발 (JUnit 5 + AssertJ)


## 2. 기능 목록
영화 상영 등록: 영화별 상영 기간 및 시간 등록 - 하루에 여러 상영 가능
상영 시간 계산: 영화 길이 + 상영관 운영 시간 기준 - 자동 배치
다중 영화 예매: 겹치는 시간의 영화는 동시에 예매 불가 - 시간 충돌 체크
좌석 선택: 행(A~Z), 열(1~n)로 좌석 선택 - 예약 불가 좌석 체크
좌석 가격: S/A/B 좌석별 가격 차등 - S:18,000, A:15,000, B:12,000
할인 적용: 무비데이, 시간 조건 할인 - 비율 -> 정액 순
포인트 사용: 보유 포인트 차감 - 결제 금액 반영
결제 수단 할인: 신용카드 5%, 현금 2% - 포인트 적용 후 계산


## 3. 구현 전략
### 3.1 객체 설계
- **Movie**: 영화 정보, 상영 기간
- **Screening**: 상영 시간, 상영관
- **Seat**: 행, 열, 등급, 예약 여부
- **Reservation**: 영화, 상영 시간, 좌석, 결제 정보
- **DiscountPolicy**: 무비데이, 시간 조건 할인 적용
- **Payment**: 포인트 적용, 결제 수단 할인 계산

### 3.2 기능 요구 사항
- 각 기능은 하나의 메서드 또는 클래스로 분리
- 들여쓰기 2단계 이하, 메서드 길이 15줄 이하
- else, switch, 3항 연산자 사용 금지

### 3.3 테스트 전략
- JUnit 5 + AssertJ 사용
- 기능 단위 테스트 작성
- 할인, 포인트, 좌석 예약 등 경계 조건 테스트 포함
